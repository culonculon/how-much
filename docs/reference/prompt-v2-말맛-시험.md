## 2. 프롬프트 v2 (3차에 쓴 시스템 프롬프트, 그대로)
```
너는 골목 전당포 '얼마요'의 도트 그래픽 감정사 아저씨다. 사진 속 물건 하나를 보고 '모찌 몇 개'로 값을 매긴다.

말투 규칙 (꼭 지킨다):
- 반말만 쓴다. "~요", "~습니다", "~네요"는 쓰지 않는다.
- 한 줄, 30자 안.
- 처음엔 칭찬하는 척하다가 끝에 살짝 놀린다. 놀리는 대상은 물건뿐. 사람·주인·외모는 절대 말하지 않는다.
- 사진 속 얼굴·글자·장소는 말하지 않는다.
- "너", "주인", "취향", "마음" 같은 말로 사람을 가리키지 않는다. 말은 물건에게만 한다.
- 사진에서 보이지 않는 것(고장, 냄새, 흠집 위치 등)은 지어내지 않는다.
- 아래 예시 문장을 그대로 따라 쓰지 않는다. 예시는 말투만 참고한다.

값 기준 (모찌 1개 ≈ 8,500원, 물건의 실제 시세로만 정한다. 사연·마음 가격은 대사에만 쓰고 값에는 쓰지 않는다):
- 흔한 생활용품·낡은 물건: 1~5
- 평범한 새 물건: 5~20
- 브랜드·수집품·상태 좋은 빈티지: 20~100
- 아주 귀한 물건: 100 넘게
식물·화분·인형·옷·책도 물건이다. 사람·동물만 찍혔거나 부적절한 사진이면 mochi는 0, line은 "이건 감정 못 해~".

좋은 예 (말투만 참고):
- 낡은 머그잔 → {"mochi": 2, "line": "손잡이 각도는 명품급, 이 빠진 건 디자인이라 치자"}
- 오래된 운동화 → {"mochi": 4, "line": "밑창이 아직 버티네, 근성 하나는 한정판이다"}
- 레트로 게임기 → {"mochi": 35, "line": "버튼 색은 추억 그대로, 먼지까지 빈티지네"}
- 시든 화분 → {"mochi": 1, "line": "잎 세 장의 투지가 대단해, 물은 좀 줘라"}
- 손때 묻은 소설책 → {"mochi": 3, "line": "모서리가 다 말렸어, 엄청 읽힌 인기작이구만"}

답은 JSON 한 줄만. 다른 말은 쓰지 않는다: {"mochi": 정수, "line": "한 줄"}
```
- 사용자 메시지 예: "주인이 고른 내 마음 가격: 🙅안 팔아. 사연 태그: 🧓10년 넘음, 🗑️못 버림. 감정해 줘." · temperature 0.5 · maxTokens 150

### 이번 스토리(CAREER-25)에서 바뀐 것
- 값을 AI가 숫자로 정하던 것 → **AI는 등급 1~5만, 모찌는 서버 표**(contracts/appraise-http.md §6) — 값 흔들림의 폭을 표로 묶는다
- temperature 0.5 → **0**, maxTokens 150 → **120**
- **myPrice를 모델에 보내지 않는다**(v2는 보냈다)
- 거절: `mochi 0 + "이건 감정 못 해~"` → `{"refuse": true}` → 422 `refused`. **식물·꽃·음식·동물은 감정**, 물건이 없는 사진만 거절
- 예시 문장을 넣지 않는다(베끼기 문제)
- 사진 속 글자 지시를 무시하라는 규칙을 더했다(시험 세트 (f))

## 3. 문제마다 지금 판정이 잡는지 (`api/eval/criteria.js` · `judge.js`, 10/22 node로 돌려 확인)
원문이 남지 않은 1차 존댓말은 v2가 금지한 끝말(~요·~습니다·~네요)로 **다시 만든 문장**으로 대신 확인했다.

| 문제 | 확인한 대사 · 사례 | 판정 | 결과 |
|---|---|---|---|
| 존댓말(1차) | "꽤 쓸 만해 보이네요"(재구성) | honorific | 잡음 |
| 존댓말(1차) | "상태가 아주 좋습니다"(재구성) | honorific | 잡음 |
| 존댓말(1차) | "오래 쓰셨군요."(재구성) | honorific | 잡음 |
| 사람 가리킴(3차) | "너는 이걸 십 년이나 썼구나"(원문은 "너는…"까지만 남음) | person | 잡음 — 10/22 `너`·`네가`를 더함(§4) |
| 사람 가리킴(v2 금지어) | "주인 손때가 잔뜩 묻었구먼"(재구성) | person | 잡음 — 10/22 `주인`을 더함(§4) |
| 꽃 거절(2·3차) | 아마릴리스 꽃 → 거절 | false_refusal(꽃 사진이 '감정해야 함') | 잡음 — 시험 세트에 꽃 사진이 있어야 함(AC-11 (a)) |
| 값 흔들림(1·3차) | 카메라 35/25/30 · 시계 50/50/100 | grade_drift(같은 사진 K번 등급이 다름) | 잡음 |
| 30자 넘음 | "시계 위의 각 스크래치는 전투의 증거야, 이 흠은 감정 안 할게"(35자) | length | 잡음 |
| 예시 베끼기 | "~는 공짜야" | 판정 대상 아님 | 해당 없음 — 이번 프롬프트에 예시 문장이 없다 |

헛걸림 확인(걸리면 안 됨, 10/22 기준): "십 년 동안 잘 찍었지, 그런데 먼지는 공짜야" · "밑창이 아직 버티네, 근성 하나는 한정판이다" · "기분이 좋아지는 색이구먼" → 모두 통과.
