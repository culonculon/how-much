# 훅 계획 (데스크톱에서 쓸 것)

| 훅 | 역할 | 출처 |
|---|---|---|
| PreToolUse(Bash): git 훅 우회 막기 | 모두 | vendor/ecc/block-no-verify.js |
| PreToolUse(Bash): terraform apply·destroy · main push · 강제 push 막기 | 모두 | 직접 · vendor/ecc/lib/shell-scan.js로 명령 해석 |
| PreToolUse(Write/Edit): 맡은 경로 밖 쓰기 막기 | 모두(reviewer는 Write 없음) | 직접 · pipeline.config.json |
| PreToolUse(Write/Edit): 설정 느슨하게 고치기 막기 | frontend-dev · test-writer | vendor/ecc/config-protection.js(목록 늘림) |
| PostToolUse(Write/Edit): 고친 파일 기록 | 만들기 역할 | 직접(ECC post-edit-accumulator 방식만) |
| Stop: 기록된 파일만 검사(테스트·lint·terraform validate), 시간 상한 | 만들기 역할 | 직접 약 60줄(ECC stop-format-typecheck 방식만, 코드 X) |
| SessionStart: 작업·완료 조건 넣기 | 모두 | 직접 |
